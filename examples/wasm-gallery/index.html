client-WASM gallery — Fitz LiveViews

Ten .fitzv components compiled to WebAssembly with fitz build --target wasm-client, in a single bundle. Each one owns its state in Rust inside the WASM instance. It all runs in the browser — no server, no WebSocket.

If you see this text but not the components, either the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules need an HTTP origin: serve with python -m http.server 8000 or equivalent.
