Galería client-WASM — Fitz LiveViews

Un componente Counter.fitzv compilado a WebAssembly con fitz build --target wasm-client. El estado vive en Rust dentro de la instancia WASM; cada click re-renderiza el subárbol. Todo corre en el browser — sin servidor, sin WebSocket.

Si ves este texto pero no el contador, o el bundle WASM no cargó (mirá la consola de DevTools) o la página se abrió por file://. Los módulos ES necesitan origen HTTP: serví con python -m http.server 8000 o equivalente.
